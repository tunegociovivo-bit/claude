Genera webs WordPress + Elementor a partir de un briefing guiado, conectado a Claude para diseño y contenidos.

== Description ==

AI Web Designer es una plataforma de diseño web automatizada para WordPress que:

* Recoge toda la información del cliente (logo, fotos, textos, dominio, contacto, referencias) mediante un wizard guiado.
* Si falta algo, lo genera la IA (texto con Claude, imágenes con OpenAI/Stability/Flux, logos, paletas, eslóganes).
* Conecta con Claude Design para generar la estructura completa del sitio.
* Construye plantillas reales de Elementor con secciones (hero, servicios, testimonios, FAQ, contacto…).
* Librería de plantillas por sector (restaurante, abogados, clínica, ecommerce, portfolio, SaaS, etc.).
* Importa información desde un dominio existente (scraping inteligente).
* Genera SEO on-page, Schema.org, textos legales (RGPD/cookies/aviso), banner de cookies, blog inicial.
* Integraciones: WhatsApp, Google Business Profile, Calendly, WPML/Polylang, GA4, Maps.
* Sistema de aprobación sección por sección, comentarios, versionado y rollback.
* Modo agencia multi-cliente, exportación del proyecto como kit Elementor, tracking de coste IA.

== Configuración ==

1. Ajustes → AI Web Designer.
2. Introduce tu Claude API key y el modelo (Opus / Sonnet / Haiku).
3. Configura proveedor de imágenes y API keys.
4. Activa modo agencia si lo necesitas.

== Roles ==

* **Administrador**: acceso completo.
* **Diseñador IA**: gestionar y aprobar proyectos.
* **Cliente Web**: rellenar briefing del proyecto asignado.
